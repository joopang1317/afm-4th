# 15분 저녁 레시피 + 나노바나나 썸네일

이 폴더(`afm-4th/week-1`)에서 반복하는 작업을 하나의 흐름으로 정리한 스킬이다.
요청에 따라 아래 단계 중 필요한 것만 실행한다.

| 단계 | 요청 예시 | 산출물 |
|---|---|---|
| 1. 레시피 작성 | "15분 저녁 레시피 하나 만들어줘" | `<레시피명>.md` |
| 2. 썸네일 생성 | "나노바나나로 썸네일 넣어줘" | `<레시피명>-thumbnail.png` + md 상단 이미지 삽입 |
| 3. 메모 기록 | "칠리소스 넣으니 맛있었어, 기록해줘" | md의 **직접 해보고 남긴 메모** 섹션에 추가 |
| 4. 커밋 | "변경사항 저장(commit)해줘" | git 커밋 |

## 1. 레시피 작성

- 파일명: `15분-저녁-레시피.md`처럼 한글 케밥 케이스. 여러 개일 때는 `15분-저녁-레시피-<요리명>.md`.
- 구조는 [templates/recipe-template.md](templates/recipe-template.md)를 그대로 따른다.
  (제목 → 썸네일 자리 → 한 줄 소개 → 조리시간/분량/난이도 → 재료 표 → 만드는 법(단계별 소요시간 병기) → 팁 → 직접 해보고 남긴 메모 → 함께 곁들이면 좋은 것)
- 15분 안에 끝나도록 **동시 진행**(예: 면 삶는 동안 소스 만들기)을 단계에 명시한다.
- 재료는 2인분 기준, 표로 작성한다.

## 2. 썸네일 생성 (나노바나나)

- 모델: `gemini-2.5-flash-image` (Google Gemini API, 일명 나노바나나).
- API 키는 **환경변수 `GEMINI_API_KEY`** 로 받는다. 사용자가 채팅에 키를 주면 그 값을 환경변수로만 한 번 사용하고, 파일·커밋에 절대 저장하지 않는다. 키가 없으면 사용자에게 요청한다.
- 실행:

```bash
GEMINI_API_KEY="<키>" python .claude/skills/dinner-recipe/scripts/gen_thumbnail.py \
  --dish "마늘 버터 새우 파스타" \
  --dish-en "garlic butter shrimp pasta with plump pink shrimp, golden garlic slices and green parsley" \
  --out thumbnail.png
```

  옵션: `--character` (기본: 센과 치히로의 치히로), `--scene` (기본: 온천장 식당), `--prompt` (전체 프롬프트 직접 지정), `--model`.
- 생성 후 Read 툴로 이미지를 **직접 확인**하고(요리·캐릭터·분위기가 맞는지), 이상하면 프롬프트를 조정해 재생성한다.
- md의 H1 제목 바로 아래에 삽입한다:

```markdown
# 마늘 버터 새우 파스타 (15분 저녁 레시피)

![치히로가 마늘 버터 새우 파스타를 먹는 장면](thumbnail.png)
```

- 이미지 모델이 캐릭터 생성을 거부하면 "지브리풍 단발머리 소녀"처럼 스타일 묘사로 바꿔 재시도하고, 사용자에게 알린다.

## 3. 시식 메모 기록

- 섹션 이름은 항상 `## 직접 해보고 남긴 메모` (팁 섹션 아래, 곁들임 섹션 위). 없으면 만든다.
- 형식: `- 🌶️ **한 줄 요약.** 상세 내용. (YYYY-MM-DD)` — 날짜는 오늘 날짜를 절대 날짜로 기록한다.
- 기존 메모는 지우지 말고 아래에 누적한다.

## 4. 커밋

- `git status --short`로 변경 파일을 확인한 뒤, 레시피 md와 썸네일 png만 `git add` 한다 (API 키 관련 파일 금지).
- 메시지 예: `docs: 15분 저녁 레시피에 칠리소스 추가 메모 기록`, `docs: 15분 저녁 레시피 추가 및 썸네일 삽입`.
- 푸시는 사용자가 요청할 때만 한다.

## 주의

- 이미지 파일은 약 2MB(1024×1024)로 생성된다. 커밋 크기가 신경 쓰이면 사용자에게 알린다.
- 이 스킬 폴더 밖(`.claude/skills/dinner-recipe/`)에는 키·토큰을 남기지 않는다.
