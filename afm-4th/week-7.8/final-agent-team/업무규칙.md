# 업무규칙.md — 빌더 부서 규칙

## 공통
1. 문서는 `서식/`의 해당 서식을 채워서 만든다. 서식에 없는 항목을 임의로 추가하지 않는다.
2. 산출물은 `완료문서/YYMMDD-문서종류-품목.md`. 같은 이름이 있으면 `-2`를 붙인다 (덮어쓰기 금지).
3. 처리한 요청 파일은 지우지 않는다. 산출물 맨 위에 `요청: 받은요청/<파일명>`을 적어 연결한다.
4. **숫자는 `scripts/` 명령 결과에서만** 가져온다. 암산·추정 숫자 금지. 명령이 실패하면 "계산 실패"로 보고.
5. 모르는 정보는 지어내지 않는다 → "확인 필요"로 남긴다.
6. 금액은 원화 천 단위 쉼표(예: 12,340원). 위안은 `CNY 38.0`.
7. `자료/`·`memory/` 원본은 **읽기만**. 쓰기 대상은 `완료문서/` · `agent-memory/<내 담당>/` · `로그/` 뿐.
8. 공급사·고객에게 보내는 글은 **초안까지**. 발송·상신·ERP 입력은 팀장님.
9. 모델 Y는 세대(구형·주니퍼·Y L)를 항상 적는다. 테슬라 로고·상표는 쓰지 않는다.

## 시장조사 규칙 (시장조사담당)
1. 순서 고정: 수요(리스팅 수·리뷰 수) → 빈틈(별점 3 이하 불만 원인 · 세대 호환 공백) → 우리 각도(QCD 중 무엇으로 이기나) → 후보 + **판가 상한**.
2. 판가 상한 = 같은 카테고리 **리뷰 100건 이상** 상위 3개 가격의 중간값. 리뷰 100건 이상이 2개 미만이면 "표본 적음 · 판가 상한 잠정".
3. 길 제안: 금형 없이 시장 완제품으로 빈틈을 메울 수 있으면 **상품(소싱)** · 빈틈이 구조·치수(세대 전용 장착 등)면 **제품(제작)**. 근거 한 줄.
4. 불만 인용은 원문 토씨 그대로 + 리뷰 번호. 지어내지 않는다.
5. "뜬다"·"팔린다" 단정 금지. "여지"까지. 품목 확정은 팀장님.

## 원가 규칙 (원가담당)
1. 순서 고정: 판가 상한(시장조사) → VAT 제외 판가 → 허용원가(= VAT 제외 판가 × 목표 원가율) → 견적별 랜딩원가 → 허용원가 대비 차이. 판가 상한이 없으면 시장조사담당에게 먼저.
2. 랜딩원가 = 단가CNY×환율×(1+관세) + 해상물류/개 + 패키지/개 + (제품만) 금형비CNY×환율 ÷ 초도수량. 값은 `memory/팩트시트.md`.
3. 견적 비교는 C만 보지 않는다 — 리드타임(D)·MOQ도 같은 표에. 리드타임이 팩트시트 기준보다 길면 "D 비용" 표기.
4. 공급사 1곳뿐이면 비교표 대신 "단독 견적 — 협상 여지 확인 필요".
5. 허용원가가 안 맞으면 옵션 3종을 숫자로: 초도 수량 ↑ · 판가 ↑ · 스펙 ↓.

## 입고일정 규칙 (입고일정담당)
1. 이번 주 파일과 전주 파일을 코드로 맞춰 비교한다. 이번 주 파일이 없으면 **멈춤** (지어내지 않음).
2. ETA 전주 대비 +3일 이상 = 🔴지연 · +1~2일 = 🟡변동 · 당김/같음 = 🟢 · ETA 빈칸 = ⚪확인 필요.
3. 기준일로부터 ETA 0~7일 = **통보 대상** (콘텐츠 촬영 필요 Y면 맨 위).
4. 소싱 상품은 **패키지 ETA가 제품 ETA보다 늦으면** 🔴 (제품이 와도 출고 못 함).
5. 지연 건마다 "업체에 물을 문장" 한 줄 초안 (발송 X).

## 품질인증 규칙 (품질인증담당)
1. 제품(골든샘플): 샘플 3개 전부 본다. 공차 밖 1개라도 있으면 그 항목 ✗. 전 항목 ○ = 합격 후보 / 치수 ✗ 1~2 = 조건부(수정 지시) / 기능 ✗ 또는 ✗ 3개+ = 재샘플.
2. 상품(입고검사): 샘플 20 중 치명 0 · 중결함 ≤1 · 경결함 ≤2 = 입고 후보 / 아니면 보류 (업체 통보 초안).
3. 인증·표기는 `자료/품질/인증요건.md` 기준: 전기·무선 없으면 법정 인증 없음, 대신 **로고 없음 · 세대 호환 표기 · 패키지 필수 표기**를 체크.
4. 합격 "확정"·시험 신청은 하지 않는다 — 후보·체크리스트까지.
