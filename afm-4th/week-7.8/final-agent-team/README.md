## 세 장면 (퀘스트 요건)
1. **자동 위임** — 이름을 부르지 않고 던진다 (AGENTS.md 라우팅 표가 넘긴다):
   ```
   받은요청 폴더에 있는 거 다 처리해줘
   ```
   → 시장조사담당·원가담당·품질인증담당·입고일정담당 4명이 동시에 돌고, 비서실이 3줄로 요약한다.
   단건 예: `모델Y 선글라스 트레이 시장 빈틈이 뭐야` · `TS-02 견적 3곳 원가 봐줘` · `SG-01 T1 샘플 판정` · `이번 주 들어오는 거 정리`
2. **기억** — `/clear` 후 `TS-02 원가` 라고만 해도: 금형 상각 규칙·패키지비·세대 표기·로고 금지가 설명 없이 반영된다 (`MEMORY.md` + `agent-memory/원가담당/MEMORY.md`).
3. **예약 실행** — `scripts/register_task.ps1`로 매주 월 09:00 등록. `weekly_inbound.ps1`이 멈출 장치 3개를 가진다: 이번 주 자료 없으면 멈춤 · 같은 날 2회 금지 · 40턴/15분 한도. 로그는 `로그/예약실행.log`.

## 실행 순서 (처음 여는 사람)
1. 이 폴더(`final-agent-team`)를 VS Code로 열고 Claude Code 세션을 연다 — **상위 폴더에서 열면 담당자를 못 본다**.
2. `받은요청 폴더에 있는 거 다 처리해줘` → 완료문서 6개 확인.
3. `브리핑` → 비서실 4블록 브리핑.
4. `powershell -ExecutionPolicy Bypass -File scripts/register_task.ps1` → 예약 등록 → `schtasks /Run /TN MT빌더_입고점검_주간` 으로 1회 즉시 실행 → `로그/예약실행.log`.

## 회고 (261024)
- **잘 된 점**: 수업 틀(총무 kit + 하루 kit)을 그대로 두고 안의 사실만 우리 부서로 바꿨더니 하루 만에 섰다. "채팅으로 먼저 해보고 담당자로 정리"하는 7주차 방식이 실제로 빨랐다. 제품(제작)과 상품(소싱)을 한 부서 안에서 다른 공식·다른 검사로 굴리는 구조가 회사 현실(스피드 회사가 Q·C를 보강하는 길)과 맞았다.
- **아쉬운 점**: 자료가 가상이라 Playwright 실검색·ERP 읽기가 빠졌다(실무 전환 1순위). 마케터 쪽(콘텐츠·광고)은 지식 아카이브가 없어 담당자를 못 만들었다. 예약 실행은 PC가 켜져 있어야 해서 24시간 컴퓨터가 필요하다.
