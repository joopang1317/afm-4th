# 인증 · 표기 요건 (⚠️ 가상 · 사내 기준 요약)
> 품목 특성 × 판매채널로 필요 여부를 본다. 법령 원문 아님 — 실제 판단은 시험기관·팀장님 확인.

## 법정 인증
| 조건 | 필요 인증·시험 | 없으면 |
|---|---|---|
| 전기·전자 부품 포함 (충전·LED·모터) | KC 전기용품 안전 | 판매 불가 |
| 무선 기능 (블루투스·무선충전·Wi-Fi) | 전파인증 (적합성평가) | 판매 불가 · 사전예약도 위법 소지 |
| 어린이용 표기 | 어린이제품 안전확인 | 표기 삭제 또는 인증 |
| 위 해당 없음 (수납·커버·트레이, 자사몰·오픈마켓) | 법정 인증 없음 · 소재 성분표 보관 권장 | — |

## 테슬라 품목 공통 체크 (인증 대신 반드시)
| 항목 | 기준 | 없으면 |
|---|---|---|
| 로고·상표 | 제품·패키지·상세에 테슬라 로고/워드마크 **없음** ("for Tesla Model Y" 호환 표기만) | 통관 보류·상표 리스크 → 판매 금지 |
| 세대 호환 표기 | 구형 / 주니퍼 / 모델 Y L 중 맞는 것만 표기, 옵션 분리 | 반품·별점 하락 (리뷰 R01·R10·R12) |
| 패키지 필수 표기 | 품명 · 호환 차종 · 소재 · 원산지 · 수입자 · 구성품 수 · 주의사항 | 표시 위반 |
| 소싱 완제품 | 공급사 자체 로고·타사 각인 없음 확인 (TS-02 A530 커버 각인) | 제외 또는 제거 조건 |
