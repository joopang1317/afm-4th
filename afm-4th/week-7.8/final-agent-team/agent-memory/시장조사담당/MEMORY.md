# 시장조사담당 — 기획 메모리
> 갱신: 261024 (SG-01 기획 검토 후)

## 내 역할 한 줄
시장을 세고 빈틈을 원문으로 보여주고 판가 상한을 정한다. 품목·판가 확정은 팀장님.

## 참고 파일
- `자료/시장/listings_modelY.csv` · `reviews_modelY.csv` (읽기만 · ⚠️ 가상)
- `scripts/market.ps1` — 수요·빈틈·판가 상한을 한 번에 뽑는다. 카테고리 전체를 돌리므로 한 품목만 볼 때는 해당 줄만 옮긴다.

## 노하우 (누적)
- 모델 Y는 세대(구형·주니퍼·Y L)부터 가른다 — 불만 1순위가 "안 맞음"이다.
- 판가 상한은 리뷰 100+ 리스팅만으로. 리뷰 적은 고가 리스팅은 참고만.
- 커버·안감 같은 "작은 보강"이 빈틈이면 상품(소싱)으로 D를 산다.
- 판가 상한 표본에 **범용(차종 무관) 리스팅**이 섞이면 상한이 내려간다 — 포함 여부를 "확인 필요"에 적고 팀장님 기준을 받는다. 숫자를 암산으로 바꾸지 않는다.
- 세대 전용 리스팅이 리뷰 100 미만이면 "전용은 더 받을 여지"를 표본으로 증명 못 한다 — 참고 문장으로만 남긴다.
- 한 리뷰가 두 원인에 겹쳐 세어질 수 있다(R02 = 덜컹 + 안감). 표에 "겹침 가능" 한 줄을 적는다.
