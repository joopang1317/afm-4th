# 팀 공용 MEMORY — 규칙과 예외만 (결과물 X)
> 갱신: 261024 · 비서실과 모든 담당자가 일을 시작하기 전에 읽는다. 담당자 개인 기억은 `agent-memory/<담당>/MEMORY.md`.

## 우리 부서의 판단축
- 회사 강점은 스피드(D). 약점은 Q·C. **D를 깎아 Q·C를 사지 않는다** — 일정을 늦추는 개선안은 "D 비용"을 같이 적는다.
- 숫자는 QCD + 매출/영업이익으로. "좋아 보인다" 금지.
- **판가에서 거꾸로**: 시장조사담당이 판가 상한을 정하면 → 원가담당은 그 안에서 허용원가 → 스펙·공급사. 견적부터 보지 않는다.

## 제품 vs 상품 (이번 회전의 두 길)
| | 제품 (직접 커스텀 제작) | 상품 (소싱 · 패키지만 자사) |
|---|---|---|
| 예 | SG-01 선글라스 트레이 | TS-02 트렁크 사이드 보관함 |
| 원가 | 단가 + **금형비 ÷ 초도수량** 포함 | 완제품 단가 + **자사 패키지비** |
| 품질 | 골든샘플(T1) **3개 측정** 판정 | 입고검사 **AQL 샘플** 판정 |
| 일정 | 금형 T0→T1→T2 (D 길다) | 발주→선적 (D 짧다) · **패키지가 제품보다 먼저** 도착해야 함 |
| 강점 | 차별화(Q) | 스피드(D) |

## 정해진 규칙 (팀장님 결정 · 날짜순)
- 261020 — 입고 **7일 전**이면 콘텐츠·CX에 통보 대상으로 표시한다.
- 261020 — ETA가 전주 대비 **3일 이상** 밀리면 "지연". 1~2일은 "변동".
- 261021 — 금형비는 **초도 수량으로 나눠** 개당 원가에 넣는다. 따로 빼서 싸 보이게 하지 않는다.
- 261022 — 골든샘플은 측정 **3개 모두** 공차 안이어야 "합격 후보". 기능 항목 1개라도 ✗면 재샘플.
- 261022 — 소싱 상품 입고검사: 치명 결함 0 · 중결함 1 이하 · 경결함 2 이하 (샘플 20) 아니면 "보류".
- 261023 — 회사 ERP·관리시트는 **읽기만**. 담당자는 `자료/`에 내려받은 사본만 쓴다. 수정·상신·발송은 팀장님.
- 261024 — **모델 Y 세대 구분 필수**: 구형(2020~24) · 주니퍼(2025~) · 모델 Y L. 둘 다 맞는지 확인 없이 "공용" 표기 금지.
- 261024 — **테슬라 로고·상표 사용 금지** (비정품). 패키지·상세는 "for Tesla Model Y" 호환 표기만. 로고 있는 소싱품은 제외.

## 예외 (이럴 땐 다르게)
- 공급사가 1곳뿐인 견적 → 비교표 대신 "단독 견적 — 협상 여지 확인 필요".
- 자료 파일이 비었거나 이번 주 파일이 없음 → 지어내지 않고 **멈춤** + 로그에 "자료 없음".
- 환율·관세가 팩트시트와 다르게 적힌 자료 → 팩트시트가 이긴다. 다른 값은 "자료 표기"로 따로 적는다.
- 제품(금형)인데 초도 수량으로 허용원가가 안 맞음 → 바로 "드랍"이 아니라 **초도 수량 ↑ / 판가 ↑ / 스펙 ↓** 세 옵션을 숫자로.
