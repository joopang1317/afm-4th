# 제육볶음 (15분 저녁 레시피)

고기 굽는 동안 양념을 섞어두면 15분 안에 끝나는 한 팬 요리. 고추장 양념이 불맛과 만나 밥 두 공기는 그냥 사라집니다.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: ⭐☆☆ (쉬움)

## 재료

| 재료 | 분량 |
|------|------|
| 돼지 앞다리살 (또는 목살) | 400g (제육용 얇게 썬 것) |
| 양파 | 1/2개 (채 썰기) |
| 대파 | 1대 (어슷 썰기) |
| 양배추 | 2장 (한 입 크기) |
| 청양고추 | 1개 (기호에 따라) |
| 고추장 | 2큰술 |
| 고춧가루 | 1큰술 |
| 진간장 | 1큰술 |
| 다진 마늘 | 1큰술 |
| 설탕 | 1큰술 |
| 맛술 (또는 청주) | 1큰술 |
| 참기름 | 1큰술 |
| 식용유 | 1큰술 |
| 통깨 | 약간 |
| 후추 | 약간 |

## 만드는 법

1. **양념장 섞기 (0~2분)**
   볼에 고추장 2큰술, 고춧가루 1큰술, 진간장 1큰술, 다진 마늘 1큰술, 설탕 1큰술, 맛술 1큰술, 후추를 넣고 섞습니다. 참기름은 마지막에 넣으니 지금은 빼둡니다.

2. **재료 손질 (2~4분)**
   양파는 채 썰고, 대파는 어슷 썰고, 양배추는 한 입 크기로 자릅니다. 청양고추는 송송 썹니다.

3. **고기 재우기 (1분)**
   고기에 양념장을 넣고 손으로 조물조물 버무립니다. 얇게 썬 고기라 오래 재울 필요 없이 바로 볶아도 간이 뱁니다.

4. **고기 볶기 (4~5분)**
   달군 팬에 식용유 1큰술을 두르고 센 불에서 고기를 펼쳐 넣습니다. 처음 1분은 건드리지 말고 두었다가 뒤집어야 불맛이 납니다. 겉면이 익을 때까지 볶습니다.

5. **채소 넣고 볶기 (2~3분)**
   양파, 양배추, 청양고추를 넣고 센 불에서 볶습니다. 양배추가 살짝 숨이 죽고 아삭함이 남아 있을 때가 딱 좋습니다.

6. **마무리 (1분)**
   대파를 넣고 30초만 더 볶은 뒤 불을 끕니다. 참기름 1큰술과 통깨를 뿌려 한 번 섞어 바로 담아냅니다.

## 팁

- 고기는 **한 번에 다 넣지 말고 팬에 펼쳐 넣으세요.** 겹쳐 쌓으면 물이 나와 볶음이 아니라 조림이 됩니다.
- 고추장은 쉽게 타므로 **불을 아주 세게 하지 말고 중강불**을 유지하세요. 팬 바닥이 검게 눌면 쓴맛이 납니다.
- 앞다리살이 없으면 목살이나 삼겹살도 됩니다. 삼겹살은 기름이 많이 나오니 식용유를 생략하세요.
- 덜 맵게 하려면 고춧가루를 반으로 줄이고 설탕을 1/2큰술 더 넣으세요.
- 양념을 2배로 만들어 반은 냉동해두면 다음에 고기만 사서 5분이면 끝납니다.
