# COIN PULSE — 실시간 코인 시세 대시보드 (Week 3 · 퀘스트 6)

CoinGecko API 기반 실시간 시세 대시보드. **API 키 불필요**, Node 내장 모듈만 사용 (의존성 0).

## 실행

```bash
node server.js            # http://localhost:3002
```

## 기능

| 기능 | 설명 |
|---|---|
| 기본 4종 | BTC · ETH · XRP · SOL |
| 검색 추가 | 코인명·심볼로 검색해 카드 추가 (CoinGecko search) |
| 삭제 | 카드 우측 ✕ |
| 30초 자동 갱신 | 남은 시간 카운트다운 표시, 수동 새로고침 버튼 |
| 등락 색상 | 상승 초록 / 하락 빨강 — 좌측 바 · 변동률 배지 |
| 변동 플래시 | 갱신 시 가격이 바뀐 카드만 초록/빨강으로 깜빡임 |
| 통화 전환 | KRW ↔ USD |
| 다크/라이트 | 테마 토글 |
| 관심 코인 저장 | localStorage — 새로고침해도 유지 |

## 서버를 둔 이유

CoinGecko는 키가 없어도 되지만 브라우저에서 직접 부르면 호출 제한에 걸리기 쉽다.
`server.js`가 프록시하면서 **20초 캐시**를 두고, 레이트리밋(429)이 나면 만료된 캐시라도 돌려준다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/prices?ids=&vs=` | 가격 · 24h 등락 · 시총 · 거래대금 |
| GET | `/api/coins?ids=` | 이름 · 심볼 · 아이콘 |
| GET | `/api/search?q=` | 코인 검색 (상위 10개) |
| GET | `/api/health` | 상태 확인 |
