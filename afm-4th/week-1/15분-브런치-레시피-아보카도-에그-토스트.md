# 아보카도 에그 토스트 (15분 브런치 레시피)

<!-- 썸네일 자리: "나노바나나로 썸네일 넣어줘"라고 요청하면 여기에 이미지가 삽입됩니다 -->

빵을 굽는 동안 아보카도를 으깨고 계란을 부치면 15분 안에 완성되는 주말 브런치. 크리미한 아보카도, 반숙 계란, 바삭한 베이컨이 한 접시에 올라갑니다.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: ⭐☆☆ (쉬움)

## 재료

| 재료 | 분량 |
|------|------|
| 식빵 (또는 사워도우·캄파뉴) | 4쪽 |
| 아보카도 (잘 익은 것) | 1개 |
| 계란 | 2개 |
| 베이컨 | 4줄 |
| 방울토마토 | 6개 (반 가르기) |
| 레몬즙 | 1작은술 |
| 올리브유 | 1큰술 |
| 소금 | 약간 |
| 후추 | 약간 |
| 페퍼론치노 또는 고춧가루 | 약간 (기호에 따라) |
| 파슬리 또는 쪽파 | 약간 (다지기) |

## 만드는 법

1. **팬 예열 + 빵 굽기 시작 (0~2분)**
   팬 두 개를 중불에 올립니다. 한쪽 팬에 베이컨을 기름 없이 올리고, 식빵은 토스터(또는 마른 팬)에 넣어 굽기 시작합니다. **여기서부터 3~5번은 동시에 진행됩니다.**

2. **아보카도 으깨기 (2분, 빵 굽는 동안 동시 진행)**
   아보카도를 반 갈라 씨를 빼고 과육을 볼에 담습니다. 포크로 살짝 덩어리가 남게 으깬 뒤 레몬즙 1작은술, 소금·후추를 넣고 섞습니다. 완전히 갈지 말고 **덩어리를 남겨야** 식감이 좋습니다.

3. **베이컨 굽기 (3~5분, 계속 진행)**
   베이컨을 중불에서 앞뒤로 뒤집어 바삭하게 굽습니다. 다 구워지면 키친타월 위에 올려 기름을 빼고, 팬의 기름은 1큰술만 남깁니다.

4. **방울토마토 볶기 (1~2분)**
   베이컨 기름이 남은 팬에 반 가른 방울토마토를 단면이 아래로 가게 올려 1~2분 굽습니다. 소금 한 꼬집만 뿌립니다.

5. **계란 프라이 (2~3분)**
   다른 팬에 올리브유 1큰술을 두르고 계란을 깨 넣습니다. 흰자 가장자리가 바삭해지고 노른자는 반숙이 되도록 중약불에서 2~3분 굽습니다. 뚜껑을 30초 덮으면 윗면이 고르게 익습니다.

6. **조립 (2분)**
   구운 빵 위에 아보카도를 듬뿍 펴 바르고, 베이컨 → 계란 프라이 → 구운 방울토마토 순으로 올립니다.

7. **마무리 (30초)**
   올리브유를 살짝 두르고 후추, 페퍼론치노, 다진 파슬리를 뿌려 바로 냅니다. 노른자가 흐르는 동안 먹는 게 가장 맛있습니다.

## 팁

- 아보카도가 덜 익어 딱딱하면 하루 전 사과·바나나와 함께 종이봉투에 넣어두세요.
- 레몬즙은 맛뿐 아니라 **갈변 방지** 역할도 합니다. 미리 만들어 둘 거라면 꼭 넣으세요.
- 빵은 두툼한 사워도우가 가장 잘 어울립니다. 식빵을 쓴다면 겉이 진하게 노릇할 때까지 구워야 아보카도 무게를 버팁니다.
- 베이컨 대신 훈제 연어를 올리면 굽는 시간이 빠져 총 10분이면 완성됩니다.
- 계란은 수란(포치드 에그)으로 바꿔도 좋지만, 15분을 지키려면 프라이가 안전합니다.
