# 마늘 버터 새우 파스타 (15분 저녁 레시피)

![치히로가 마늘 버터 새우 파스타를 먹는 장면](thumbnail.png)

간단하지만 근사한 한 그릇 저녁. 파스타 삶는 동안 소스를 만들면 15분 안에 완성됩니다.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: ⭐☆☆ (쉬움)

## 재료

| 재료 | 분량 |
|------|------|
| 스파게티 면 | 200g |
| 냉동 새우 (칵테일 새우) | 200g |
| 마늘 | 5쪽 (편 썰기) |
| 버터 | 2큰술 |
| 올리브유 | 1큰술 |
| 페퍼론치노 (또는 고춧가루) | 3~4개 (기호에 따라) |
| 소금, 후추 | 약간 |
| 파슬리 가루 또는 쪽파 | 약간 |
| 파마산 치즈 (선택) | 약간 |
| 레몬즙 (선택) | 1작은술 |

## 만드는 법

1. **면 삶기 (0~10분)**
   끓는 물에 소금 1큰술을 넣고 스파게티를 봉지 표기 시간보다 1분 짧게 삶습니다. 면수 1/2컵은 따로 남겨둡니다.

2. **새우 준비 (2분)**
   냉동 새우는 찬물에 헹궈 해동하고 키친타월로 물기를 제거합니다. 소금·후추를 살짝 뿌립니다.

3. **마늘 버터 소스 만들기 (4~5분)**
   팬에 올리브유와 버터를 넣고 중약불로 녹인 뒤, 편 마늘과 페퍼론치노를 넣어 노릇하게 향을 냅니다. 마늘이 타지 않게 주의하세요.

4. **새우 볶기 (2~3분)**
   불을 중불로 올리고 새우를 넣어 양면이 분홍빛이 될 때까지 볶습니다.

5. **면과 합치기 (2분)**
   삶은 면과 면수를 팬에 넣고 소스가 면에 고루 배도록 빠르게 섞습니다. 소스가 걸쭉해지면 불을 끕니다.

6. **마무리**
   레몬즙, 파슬리, 파마산 치즈를 뿌려 접시에 담아냅니다.

## 팁

- 면수의 전분이 소스를 면에 잘 붙게 해주니 꼭 남겨두세요.
- 새우 대신 베이컨이나 버섯을 넣어도 잘 어울립니다.
- 매운맛을 원하면 페퍼론치노를 부숴서 넣으세요.
- 남은 면은 밀폐 용기에 담아 냉장 보관 후 다음 날 팬에 데워 먹으면 됩니다.

## 함께 곁들이면 좋은 것

- 간단한 그린 샐러드
- 마늘빵 또는 바게트
- 화이트 와인 한 잔 🍷
